# Release of Canton 3.6.4

Canton 3.6.4 has been released on October 22, 2026.

## Summary

This is a security maintenance release that updates the canton docker base image.

## What’s New

### Security Improvements

Bumped the docker base image to 1.0.17 which includes the updated version of CA CERT that excludes the compromised eMudhra root certificates and updated system dependencies.

## Compatibility

The following Canton protocol versions are supported:

| Dependency                 | Version                    |
|----------------------------|----------------------------|
| Canton protocol versions   | 34, 35, 36          |

Canton has been tested against the following versions of its dependencies:

| Dependency                 | Version                    |
|----------------------------|----------------------------|
| Java Runtime               | OpenJDK 64-Bit Server VM (build 21.0.12+2-nixos, mixed mode, sharing)               |
| Postgres                   | Recommended: PostgreSQL 17.11 (Debian 17.11-1.pgdg13+2) – Also tested: PostgreSQL 14.24 (Debian 14.24-1.pgdg13+2), PostgreSQL 15.19 (Debian 15.19-1.pgdg13+2), PostgreSQL 16.15 (Debian 16.15-1.pgdg13+2), PostgreSQL 18.6 (Debian 18.6-1.pgdg13+2)           |

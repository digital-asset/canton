# Release of Canton 3.7.1

Canton 3.7.1 has been released on October 30, 2026.

## Summary

This patch release introduces configuration options for GCP KMS key deletion notice periods.

## What’s New

### Minor Improvements
- GCP KMS key deletion notice periods can now be configured via `destroyScheduledDuration`, and values must be within 24h and 120 days. The default remains 30 days, matching the previous default value.

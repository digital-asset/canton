# Release of Canton 3.6.2

Canton 3.6.2 has been released on October 15, 2026.

## Summary

This patch release fixes a slow Ledger API query that could stall the initialization of the ACS commitment processor
in Canton 3.6.1 by using index lookups.

## What’s New

### Event sequential id range lookup of Ledger API update streams with index scans
#### Background
Canton 3.6.1 contains a slow database query that can cause SQL timeouts and stall the long-running initialization
of the new ACS commitment processor. SVs and high-volume validators are the most likely to be affected.

The slowdown came from how the Ledger API server mapped a requested offset range to the corresponding range of event
sequential ids. The query aggregated over every `lapi_update_meta` row in the offset range, so its cost grew with
the size of that range.

#### Specific Changes
- The event sequential id range is now resolved with two index lookups on `lapi_update_meta`, so the cost no longer
  depends on the size of the offset range.

#### Impact and Migration
Starting an update stream over a large offset range is now cheaper. As a result, the ACS commitment processor
initializes faster and is less likely to hit SQL timeouts. Ledger API results are unchanged, and no migration
is required.
